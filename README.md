WIP Demo for the MAC 30th anniversary webpage. 

Details and Features:
- Horizontal timeline across the screen
- Horizontal scroll ability when clicked in on the timeline component, vertical scroll without 
- Each node or point on the timeline can be hovered on or clicked.
- When hovered, the event date, name, and description pop-up and disappear when the mouse leaves the area.
- When clicked, the pop-up stays open even after moving the mouse away. Can be closed with a button.
